- Первый стабильный релиз RoutaMi: форк FlClash и SlClash на официальном ядре MetaCubeX mihomo v1.19.31.
- Новый интерфейс на единой дизайн-системе.
- Локальный прокси-порт по умолчанию требует логин и пароль; их можно посмотреть, скопировать и перегенерировать.

- Встроенный апдейтер сравнивает версии с учётом rc-сборок.
