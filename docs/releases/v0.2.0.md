- Второе ядро Xray-core: профиль работает на mihomo или на Xray, JSON-подписки (Remnawave, Happ и т. п.) — на Xray.
- При импорте по URL можно выбрать ядро; у каждого профиля виден бейдж ядра.
- Узлы Xray переключаются без перезапуска ядра, работают проверка задержки и учёт трафика.
- Настройки, которые есть только у mihomo, для Xray-профилей тусклые и по нажатию объясняют почему.
- Подписка запрашивается с User-Agent `RoutaMi/<версия> <ядро>/<версия>`; если сервер вернул не Clash-конфиг, приложение это объясняет.
