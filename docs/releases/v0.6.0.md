- Тёмная AMOLED-тема с четырьмя акцентами и новая главная: карточка маршрута, режимы, скорость сети и узлы выбранной группы.
- На главной виден внешний IP и страна; проверка повторяется при запуске, остановке, смене режима и узла. Пока прокси работает, в кнопке старта вращается шар.
- Windows: в широком окне главная в две колонки, профили и настройки — список с подробностями рядом, профиль добавляется в диалоге.
- Группы прокси карточками, иконки узлов из флага или символа в имени; настройки раскрываются на месте; профиль добавляется из одного окна по ссылке, QR-коду или файлу.
- TUN больше не выключается, когда подписка применяется при запуске; трей Windows не теряет последний ответ ядра.
